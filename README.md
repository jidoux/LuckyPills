# LuckyPills

This is a heavily modified remix of [LuckyPills made by BuildBoy12](https://github.com/BuildBoy12-SL/LuckyPills). It has the same concepts and most of its original effects, but is heavily altered beyond that with over 3x more pill effects. ## What is it?

LuckyPills is a heavily-configurable plugin for LabAPI that redefines Painkillers to be a mystery box. Never before has consuming Painkillers caused such unbelievable outcomes... but don't just take my word for it. Who doesn't like gambling, anyway? (in a video game) (dont gamble for real)

## Setup

Its a standard installation, no dependencies. Below is the process for any beginners:

1. Download the latest version of `LuckyPills.dll` from the releases page.
2. Place `LuckyPills.dll` into `<SCP_DIRECTORY>/LabAPI/plugins/global/`. SCP_DIRECTORY would be wherever your SCP Secret Laboratory folder is. For example, I get to my SCP_DIRECTORY on Windows by doing %appdata% in File Explorer and then going to the "SCP Secret Laboratory" folder from there.
3. Start/restart SCP: Secret Laboratory Dedicated Server. Feel free to edit any config values at `<SCP_DIRECTORY>/LabAPI/configs/<YOUR_SERVER_PORT>/LuckyPills/`.
